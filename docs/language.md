## 1. Введение

Этот документ описывает **первую версию языка Azy** — набор лексических и синтаксических правил, которые уже реализованы в компиляторе. Всё, что не описано здесь, считается **ещё не реализованным** и относится к будущим версиям.

Цель документа — зафиксировать текущее состояние языка: что именно понимает компилятор на сегодняшний день, какие конструкции поддерживаются, а какие — нет.

## 2. Лексика

### 2.1. Расширение файлов

Исходные файлы Azy имеют расширение **`.azy`**. Лексер отказывается обрабатывать файлы с другим расширением.

### 2.2. Пробельные символы

Пробелы, табы, переводы строк и возврат каретки **игнорируются** лексером и служат только разделителями токенов.

### 2.3. Идентификаторы

**Правило:** идентификатор начинается с латинской буквы или `_`, продолжается буквами, цифрами или `_`.

```
identifier := (letter | "_") (letter | digit | "_")*
letter     := "a".."z" | "A".."Z"
digit      := "0".."9"
```

Примеры:
```
x
counter
my_var
_value
sum2
```

Чувствительность к регистру — **есть**: `value` и `Value` — разные идентификаторы.

### 2.4. Ключевые слова

Следующие слова зарезервированы и **не могут** использоваться как идентификаторы:

| Ключевое слово | Назначение |
|---|---|
| `var`  | объявление переменной |
| `fn`   | определение функции — TODO |
| `def`  | синоним `fn` — TODO |
| `if`   | условный оператор |
| `else` | альтернативная ветка `if` |
| `while`| цикл с предусловием |
| `do`   | цикл с постусловием (в паре с `while`) |
| `for`  | цикл (три формы) |
| `in`   | часть `for … in` (foreach) |
| `return` | возврат из функции — TODO |
| `break`  | прерывание цикла |
| `continue` | переход к следующей итерации |
| `not`  | логическое отрицание (синоним `!`) |
| `true` | булев литерал |
| `false`| булев литерал |

> **Планируемое изменение:** `print` будет добавлен в список ключевых слов в следующей версии. Пока `print` — обычный идентификатор, распознаваемый парсером как встроенная функция вывода. До момента добавления в лексер технически переменную можно назвать `print`, но её вызов будет конфликтовать с оператором вывода.

### 2.5. Литералы

#### Целые числа (`Int`)

```
int_literal := digit+
```

Примеры: `0`, `42`, `1000`, `007`.

#### Числа с плавающей точкой (`Float`)

```
float_literal := digit+ "." digit* | "." digit+
```

Примеры: `3.14`, `.5`, `10.`, `0.0`.

> **Замечание:** `3.` распознаётся как `Float`, а не как `Int` + `Dot`. Для языка с доступом к полям это может стать проблемой в будущем.

#### Строки (`String`)

```
string_literal := '"' any_char* '"'
```

Строка начинается и заканчивается **двойной кавычкой** `"`.

Примеры: `"Hello"`, `""`, `"Azy Language"`.

> **Ограничение v0.1:** escape-последовательности (`\"`, `\n`, `\t`) **не поддерживаются**. Незакрытая строка не считается ошибкой лексера — просто возвращается токен с тем, что успело накопиться.

#### Булевы значения (`Bool`)

```
bool_literal := "true" | "false"
```

### 2.6. Комментарии

Поддерживаются три вида комментариев:

| Синтаксис | Тип |
|---|---|
| `# …`        | однострочный до конца строки |
| `// …`       | однострочный до конца строки |
| `/* … */`    | многострочный, **без вложенности** |

Примеры:
```azy
# комментарий через решётку
// комментарий через двойной слэш
/* многострочный
   комментарий */
```

> **Ограничение:** вложенные `/* /* */ */` не поддерживаются.

### 2.7. Операторы и разделители

| Категория | Токены |
|---|---|
| Арифметические | `+` `-` `*` `/` |
| Присваивание | `=` `+=` `-=` `*=` `/=` |
| Инкремент / декремент | `++` `--` |
| Сравнение | `==` `!=` `<` `>` `<=` `>=` |
| Логические | `&&` `\|\|` `!` |
| Разделители | `(` `)` `{` `}` `[` `]` |
| Пунктуация | `;` `,` `:` `.` |

> **Замечание:** одиночные `&` и `|` **не поддерживаются** — они становятся токеном `Unknown`.

### 2.8. Позиция токена

Каждый токен хранит:
- **строку** (`line`) — начиная с 1;
- **колонку** (`column`) — начиная с 1.

Это используется в диагностике.

## 3. Синтаксис

### 3.1. Программа

Программа — это последовательность операторов (statements), разделённых `;` там, где это требуется.

```
program := statement*
```

### 3.2. Операторы (statements)

Поддерживаются следующие операторы:

```
statement := assignment
           | postfixStatement
           | ifStatement
           | whileStatement
           | doWhileStatement
           | forStatement
           | breakStatement
           | continueStatement
           | printStatement
```

#### 3.2.1. Присваивание

```
assignment := IDENTIFIER ("=" | "+=" | "-=" | "*=" | "/=") expression ";"
```

Примеры:
```azy
x = 10;
counter += 5;
sum -= 3;
fact *= 2;
avg /= 4;
```

> **Планируемое изменение:** в будущих версиях объявление переменной будет выполняться через `var`, например `var x = 10;`. Пока эта форма не реализована в парсере.

#### 3.2.2. Постфиксный инкремент / декремент (как оператор)

```
postfixStatement := IDENTIFIER ("++" | "--") ";"
```

Примеры:
```azy
counter++;
counter--;
```

> **Ограничение:** префиксные `++counter` / `--counter` **не поддерживаются** как отдельные операторы.

#### 3.2.3. Условный оператор `if`

```
ifStatement := "if" "(" expression ")" block
              ( "else" ( ifStatement | block ) )?
```

Примеры:
```azy
if (a == 10) {
    message = "равно";
}

if (a > 100) {
    message = "больше";
} else {
    message = "не больше";
}

if (a == 1) {
    r = "one";
} else if (a == 2) {
    r = "two";
} else {
    r = "other";
}
```

#### 3.2.4. Цикл `while`

```
whileStatement := "while" "(" expression ")" block
```

Пример:
```azy
i = 0;
while (i < 10) {
    i++;
}
```

#### 3.2.5. Цикл `do … while`

```
doWhileStatement := "do" block "while" "(" expression ")" ";"
```

Пример:
```azy
k = 0;
do {
    k++;
} while (k < 5);
```

Тело цикла гарантированно исполняется **минимум один раз**.

#### 3.2.6. Цикл `for`

Поддерживаются **три формы**:

**Форма 1 — сокращённая:**
```
for ( IDENTIFIER "==" expression ) block
```
Пример:
```azy
for (i == 5) {
    print(i);
}
```
Семантика: переменная `i` инициализируется нулём по умолчанию, шаг — `i++` по умолчанию, тело исполняется, пока `i == 5`.

**Форма 2 — полная C-style:**
```
for ( IDENTIFIER "=" expression ";" expression ";" forStep ) block

forStep := IDENTIFIER ("++" | "--")
         | IDENTIFIER "=" expression
```
Примеры:
```azy
for (i = 0; i == 10; i++) {
    print(i);
}

for (i = 0; i == 10; i = i + 2) {
    print(i);
}
```

**Форма 3 — foreach:**
```
for ( IDENTIFIER "in" expression ) block
```
Пример:
```azy
text = "abc";
for (ch in text) {
    print(ch);
}
```
Итерируется по строке; переменная `ch` получает каждый символ.

> **Ограничение v0.1:** foreach работает только со строками. Обход массивов — TODO.

#### 3.2.7. `break` и `continue`

```
breakStatement    := "break" ";"
continueStatement := "continue" ";"
```

Пример:
```azy
for (i = 0; i == 10; i++) {
    if (i == 5) {
        break;
    }
    print(i);
}
```

#### 3.2.8. Оператор вывода `print` / `print.ln`

```
printStatement := "print" ( ".ln" )? "(" expression ")" ";"
```

- `print(expr);` — вывод без перевода строки;
- `print.ln(expr);` — вывод с переводом строки.

Пример:
```azy
print("без переноса");
print.ln("с переносом");
print(42);
print.ln(3.14);
```

> **Планируемое изменение:** `print` будет добавлен в список ключевых слов в лексере. Это зафиксирует его статус встроенной функции на уровне лексики и запретит использовать `print` как имя переменной.

#### 3.2.9. Блок кода

```
block := "{" statement* "}"
```

Блок — последовательность операторов в фигурных скобках. Используется в `if`, `while`, `do`, `for`.

### 3.3. Выражения

Выражения разбираются с классическим приоритетом операторов (от низшего к высшему):

```
expression     := logicalOr
logicalOr      := logicalAnd ( "||" logicalAnd )*
logicalAnd     := equality   ( "&&" equality )*
equality       := relational ( ( "==" | "!=" ) relational )*
relational     := additive   ( ( "<" | ">" | "<=" | ">=" ) additive )*
additive       := multiplicative ( ( "+" | "-" ) multiplicative )*
multiplicative := unary ( ( "*" | "/" ) unary )*
unary          := ( "-" | "!" | "not" ) unary | primary
primary        := INT | FLOAT | STRING | BOOL | IDENTIFIER
                | "(" expression ")"
                | IDENTIFIER ( "++" | "--" )
```

**Особенности:**
- Все бинарные операторы **левоассоциативны**: `10 - 5 - 2` → `(10 - 5) - 2 = 3`.
- Приоритет `*` / `/` выше `+` / `-`: `2 + 3 * 4 = 14`.
- Унарный минус и `!`/`not` связываются сильнее `*`.
- Скобки `( … )` меняют порядок вычисления.
- Постфиксные `++` / `--` разрешены внутри выражений: `value = counter++`.

**Примеры:**
```azy
x = 2 + 3 * 4;              # 14
y = (2 + 3) * 4;            # 20
z = 10 - 5 - 2;             # 3
neg = -5;
mixed = -3 * -2 + 10;       # 16
c = !(a == 10) || !(b != 0);
```

## 4. Семантика — предварительные заметки

> Семантический анализ в v0.1 **не реализован**. Ниже — зафиксированные договорённости, которые лягут в основу следующих версий.

- **Области видимости:** предполагаются лексические.
- **Типы:** динамическая типизация на этапе интерпретации (в v0.1 не проверяется).
- **`break` / `continue`:** допустимы только внутри циклов — проверка отложена.
- **`for (i == N)`:** `==` в контексте `for` трактуется как «пока не достигнуто N», а не как равенство.
- **`var`:** объявление переменной; в будущих версиях — обязательное ключевое слово при первом появлении переменной.

## 5. Диагностика ошибок

### 5.1. Ошибки лексера

Лексер сообщает о незнакомом символе через токен `TokenType::Unknown` с координатами.

Пример сообщения:
```
[Лексер] Ошибка в строке: 12, символ: 5
```

Незакрытая строка **не** считается ошибкой лексера в v0.1 — токен `String` просто получает усечённое значение.

### 5.2. Ошибки парсера

Парсер выбрасывает `std::runtime_error` с сообщением вида:

```
[Ошибка парсера] Ожидалась закрывающая скобка ')' (строка: 7, символ: 15, токен: '}')
```

Сообщение содержит:
- текст ошибки;
- номер строки;
- номер колонки;
- значение токена, на котором произошла ошибка.

## 6. Полный пример

```azy
# Полный тест возможностей языка Azy v0.1

i = 42;
f = 3.14;
s = "Hello, Azy!";
t = true;

# Арифметика и приоритет
x = 2 + 3 * 4;      # 14
y = (2 + 3) * 4;    # 20

# Логика
c = (x > 5) && (f < 10.0) || (s == "no");

# Условия
if (i == 42) {
    print.ln("Ответ найден");
} else {
    print.ln("Мимо");
}

# Циклы
counter = 0;
while (counter < 3) {
    print(counter);
    counter++;
}

k = 0;
do {
    k++;
} while (k < 5);

for (i = 0; i == 10; i++) {
    if (i == 5) {
        continue;
    }
    print(i);
}

text = "abc";
for (ch in text) {
    print(ch);
}

for (j == 3) {
    print(j);
}
```

## 7. Что НЕ реализовано (v0.1)

- Объявление переменной через `var x = …;` — ключевое слово зарезервировано, но в грамматике пока не используется
- Префиксные `++` / `--` (`++i`, `--i`)
- Массивы: литералы `[1, 2, 3]`, индексация `arr[0]`, присваивание по индексу
- Функции: `def name(args) { … }`, вызовы, `return`
- Встроенные функции: `len`, `range`
- Тернарный оператор `? :`
- `switch / case / default`
- Escape-последовательности в строках (`\"`, `\n`, `\t`)
- Вложенные блочные комментарии
- Приведение `fn` / `def` к рабочей грамматике (сейчас зарезервированы, но не используются)
- Семантический анализ: проверка типов, областей видимости, выход из цикла
- Интерпретация AST и кодогенерация
- Добавление `print` в список ключевых слов лексера

## 8. Известные ограничения лексера

1. **Статическое состояние** — `LastChar`, `current_line`, `current_col` хранятся в статике функции, что мешает параллельной работе с несколькими файлами.
2. **Рекурсия в комментариях** — на файле с большим числом комментариев возможен переполнение стека.
3. **`3.` — Float, а не `Int` + `Dot`** — может усложнить работу с полями объектов.
4. **Одиночные `&` и `|`** — не распознаются.
